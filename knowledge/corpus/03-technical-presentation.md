# Technical Presentation: Real Time Web Partners

Slide-by-slide transcript of a 46-slide partner deck. Local images were named in the export and are not in this repository. Spelling from the deck is kept. Do not volunteer the phone number on the last slide.

## Company manifesto

We see the Web as the world's biggest marketplace and an unparalleled platform for innovation. A web that rewards and protects the people who create value. Guiding principle: eternal widespread ownership of the Web. Upgrade the Web by adding new dimensions. Machines will use the Real Time Web the way humans use the World Wide Web, linking resources across domains, silos, and network layers. They provide tools for developers and machines.

## Information versus data

Speaker note, slide 3: humans like historical information and cannot process faster than their own pace. A person requests information from behind a window. Linking has already happened against underlying pages, and the page owner may not know what you are reading. Anyone can link past, present, and future, with no installation. For runtime data you need an API, and then you only know the party you connect to, not the underlying information. Sharing through APIs at many levels is expensive. Each database stores the others' data, and nobody knows who has the master or the freshest data. That is determined by context.

## Several networks

Speaker note, slide 4, originally Norwegian: compare the World Wide Web with RTW. An operating system like Synx could allow several open networks. In the future there may be several self-scaling networks, perhaps 10 to 12, that absorb each other until 3 or 4 remain: typically one public, one military, one commercial, and one open. Linking between them can still exist. Acquisitions would leave a low number of large networks.

## Physical web

On-slide: Physical World, Real Time Web, World Wide Web.

Speaker note: the web is analogous to a PC. WWW is the hard disk. RTW is internal memory. The physical world is the resources that used to be text, image, video. A resource is any object. The more one object shares data, the stronger it becomes for the collective.

## What the deck says data is worth

Slide 36 note: raw data from physical objects has a value, not only the objects. Data is the object's value in a virtual world and a marketplace.

Slide 45, Neural Network Project, on-slide:

- Data are transformed across layers and networks
- No programming is needed to build complex systems
- Domain owners keep their business logic (IP) intact (Predicate)
- End user keeps control of the data (privacy preserved)
- Predicate implemented will be used in various contexts
- Linkable domains and services are available across network layers
- Domain instances are available for any communication protocols
- Machines and humans can build systems ad hoc by creating links

Speaker note: data in a database that generates new data from old data is also a potential source. Historical data has no real value. Real-time data has a value. Data generators have a value because they can produce real-time data. Making data a commodity is about real-time data. Historical data can become real-time when it produces new data, such as an analytic engine. To make data a commodity you protect and identify the source. Raw data can be altered along the path. The more the raw data has been altered, the more value the raw data has, in this note. Any data source can be a generator for a service or a consumer.
