# Real Time Web — Brand Strategy

Date: 9 December 2014. Prepared by Maskinen, in cooperation with Synaptic Technologies. This is a brand framework, not a 2026 product specification. Where a 2026 public page disagrees, prefer the public page.

## Vision

Eternal widespread ownership of the Web.

They see the Web as the world's biggest marketplace and an unparalleled platform for innovation. They want a web that rewards and protects the people who create value. The guiding principle is eternal widespread ownership of the Web. They want to upgrade the Web by adding new dimensions.

## Mission

Enable an open ecosystem for the Real Time Web — an intelligent network that will continuously evolve.

The ecosystem is network infrastructure, software, and objects needed to connect the physical world to the virtual world, and the other way, in real time. They hoped RTW could become the standard of the Internet of Things or Everything. The claim: one can link to things the way the Web already links to files and computers. More applications grow the network.

## Values

Empower good forces: people, companies, and organisations who are passionate, considerate, and create something of real value. The opposite they name is exploitive, cynical, greedy, anti-social.

Core values: Reciprocity (what we give comes back). Simplicity (simplification makes complex work possible). Community (open source, share ideas, build on each other).

## Brand personality

An informal visionary. Clear ideas, but the focus is the next step and how others take part.

Open: welcoming, transparent, trust. Creative: a toolbox for creative spirits. Generous: creators keep full ownership of what they make, and the majority of the revenue stream they generate.

## Target audience

Settlers chasing new opportunities. First movers, personal risk, a greater good or an advantage. Motivation can be personal, or social and business. They call it a blue ocean. Available from the largest corporations to teen innovators.

Developers need documentation, performance, a community, and a long-term view, and they recommend tools to management.

Partners means educational institutions, direct customers, consortiums, seminars, and consultancies.

## Position and promise

Position: universal building blocks. They say nobody else offers the same versatility or the ability to build on each other's applications.

Promise: we let anyone connect anything to the present, through bi-directional linking, unlike APIs and middleware. The Web collects, stores, and transmits linked data. The Real Time Web is described as a network designed to process the virtual and physical present. They compare the missing idea of "Now" to mathematics lacking zero. RTW does not store information. It provides real-time data. That data can be accessed, managed, and stored through the Web. It can run as many instances, connected to the Web or detached, on a wide range of carriers.

## Brand proof

Endless digital physical innovation. Four features:

1. Shared global marketplace. A billing engine embedded into core web technology. Open source plus private ownership. Creators interact in one framework and build on each other's applications.

2. Security by design. Said to be developed by security experts with military background and standards. Aimed at resisting hacking and surveillance, respecting privacy and ownership, and safeguarding transactions. This is a 2014 claim, not an audit.

3. Ultra compatible. Common RF specification for wireless sensor networking, and wide protocol support. Backwards compatible with the Web, and able to operate in intranet environments. The network can define a need so others provide the data or application. Every owner defines transaction values. The default value is zero.

4. Most cost efficient. Bi-directional linking is claimed to reduce development cost because API and middleware are not needed. They say creators get a predictable cost and revenue structure.

## Brand concept

Make amazing things together. They compare the creative investment to Minecraft, except the result is meant to reach the physical world. Success depends on three points they list: creators must find them and believe they are the future; individuals must see the potential; the platform enables, and the users generate the value.

Signed Maskinen, 9 December 2014.
